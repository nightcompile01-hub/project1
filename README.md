# Amazon Homepage Clone

A responsive front-end clone of the Amazon homepage, built as a hands-on practice project to strengthen core HTML and CSS skills.

## 🚀 Live Demo
[View Live](https://nightcompile01-hub.github.io/amazon-clone/)

## 🛠️ Tech Stack
- HTML5
- CSS3 (Flexbox / Grid)

## ✨ Features
- Responsive navbar with search bar and account menu
- Hero banner section
- Product category cards
- Footer with Amazon-style layout
- Mobile-friendly design
